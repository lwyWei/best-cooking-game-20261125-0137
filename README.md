Sizzle & Serve is a tiny kitchen rush game: orders pile up on the board, you stack ingredients on your plate from the counter, and serve before the customer walks out. 120 seconds on the clock, combos for fast serves, and a rush that speeds up as you serve. Six recipes, eight counter stations, mouse or keyboard — click a station (or press 1–8) to stack, Space to serve, Backspace to trash the plate.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# then open out/game/index.html in a desktop browser
```
